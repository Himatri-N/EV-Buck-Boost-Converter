# EV Buck-Boost Converter

## Overview

This project presents a DC-DC Buck-Boost Converter model developed in MATLAB/Simulink using basic Simulink blocks.

The objective is to understand the working of a buck-boost converter and analyze its ability to provide a controlled output voltage from a variable DC input, which is relevant to electric vehicle power conversion applications.

## Tools Used

* MATLAB
* Simulink
* Basic Simulink blocks

## Key Features

* DC-DC voltage conversion
* Buck and boost operating behavior
* Analysis of input and output voltage
* Observation of output response under different operating conditions
* Basic simulation and waveform analysis

## Model

The converter is implemented using fundamental Simulink blocks such as:

* DC Voltage Source
* MOSFET/Switch
* Inductor
* Diode
* Capacitor
* Load Resistance
* Voltage Measurement
* Scope

## Results

The simulation was used to observe the output voltage response and verify the basic operating principle of a buck-boost converter.

## Application

Buck-boost converters can be used in EV power electronics to regulate voltage between the battery and other electrical systems when the required voltage may be higher or lower than the available battery voltage.
